# Build Checklist — {{PROJECT_NAME}}

## Before implementation

- [ ] Read current state, blueprint, queue, handoff, open PRs/issues, and CI.
- [ ] Define one bounded objective and acceptance criterion.
- [ ] Record dependencies, inputs, outputs, and risks.

## Before handoff

- [ ] Relevant deterministic tests pass or exact failures are recorded.
- [ ] Documented direct commands were exercised exactly as written.
- [ ] CI preserves diagnostics when validation fails.
- [ ] New tools/components have integration metadata and docs.
- [ ] Generated output is separated from source/evidence.
- [ ] No secrets or credentials were added.
- [ ] Current state and handoff reflect repository truth.
- [ ] Exact next action is explicit.
