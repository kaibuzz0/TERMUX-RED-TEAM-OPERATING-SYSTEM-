# Release Gates

## Pre-alpha gate

- [ ] Architecture documents approved.
- [ ] Canonical source declared.
- [ ] Security invariants defined.

## Alpha gate

- [ ] Canonical dispatcher works on desktop Linux.
- [ ] Basic `hive status`/`doctor` work in Termux emulator/static tests.
- [ ] No production code regressions.

## Beta gate

- [ ] Install/update/repair tested on physical Android.
- [ ] Vault and session gate tested.
- [ ] Hermes plugin tested with mocked tools.
- [ ] Security tests pass.

## Release gate

- [ ] Full physical Android validation plan executed.
- [ ] Independent blueprint reviews completed with no blockers.
- [ ] Supply chain audit clean.
- [ ] Release artifacts signed.
- [ ] Rollback path verified.
