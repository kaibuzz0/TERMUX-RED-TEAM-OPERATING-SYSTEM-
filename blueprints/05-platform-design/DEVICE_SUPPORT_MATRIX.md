# Device Support Matrix

| Device class | Termux standard | Termux:API | Root | PRoot | Custom ROM |
|--------------|-----------------|------------|------|-------|------------|
| Modern ARM64 phone/tablet | Primary | Optional | Optional | Optional | Future |
| Older ARMv7 device | Supported | Optional | Optional | Optional | Future |
| x86_64 emulator | Test/dev | Optional | Optional | Optional | Future |
| Chromebook (Linux container) | Desktop Linux profile | N/A | N/A | Optional | N/A |

## Minimum target

- Android 9+ (API 28).
- Termux from F-Droid.
- 2 GB RAM, 1 GB free storage for base install.
