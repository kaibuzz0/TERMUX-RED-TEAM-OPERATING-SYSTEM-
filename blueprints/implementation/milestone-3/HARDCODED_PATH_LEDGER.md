## Reachability summary

| Pattern | Files affected | Estimated severity |
|---------|----------------|--------------------|
| `/root/hive` | 41 | critical (Termux incompatible) |
| `/root/` | 5 | high (Termux incompatible) |
| `/usr/local` | 0 | none |
| `/opt/hive` | 0 | none |
| `[A-Za-z]:\\` | 1 | medium (Windows host artifact; verify false positives) |

## Risk summary

- `/root/hive` and `/root/` are incompatible with Termux and most non-root Android devices.
- `/usr/local` and `/opt/hive` are desktop-Linux FHS paths and may not exist on Termux.
- Windows drive letters are Windows host artifacts; most matches in `.py` files are escaped newlines (`\n`) in string literals, not actual drive paths. True Windows drive paths must still be eliminated from any cross-platform code.

## Recommended replacements

- Use `$HOME/.local/share/hive` or `$PREFIX/var/lib/hive` for state.
- Use repository-relative paths for bundled assets.
- Use `lib/hive_path.py` as the single source of truth for path resolution.

## Deferred changes

No broad replacement performed in Milestone 3. Specific path repairs will be scoped to later milestones once interpreter and launcher contracts are fully validated on Termux. The only acceptable near-term repairs are launcher-path related.
