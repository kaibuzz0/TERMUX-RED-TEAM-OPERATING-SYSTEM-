# Hive Symbolic Language (HSL) Definition
# Protocol for environment mapping and registry communication

- **FIRE**: Active service, daemon, runtime, or process (e.g., Hive dashboard server, active agent).
- **EARTH**: Storage, configuration, static data, documentation (e.g., skills, logs, audit files).
- **WATER**: Dynamic flows, event logs, temporary state (e.g., journals, temp files).
- **AIR**: Network connections, communication protocols, external interface points.

Registry Format:
- NAME: Symbol | PATH: /absolute/path | ROLE: Descriptive summary
