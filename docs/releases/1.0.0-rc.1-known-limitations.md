## FINAL_1_0_BLOCKER

**#12 — Production signing ceremony not yet exercised.**

Before Hive OS 1.0.0 can be declared a production release, the owner-controlled offline Ed25519 signing ceremony must be performed and verified. This is the single explicit blocker for final release.

## SHOULD_FIX_BEFORE_1_0

**#6 — Native non-root permission-failure behavior not fully validated.**

This should be addressed before final release if possible, but does not block RC stabilization.

## ACCEPTABLE_1_0_LIMITATION

All other items are accepted limitations that do not block final release, provided they remain documented and do not introduce regressions.
