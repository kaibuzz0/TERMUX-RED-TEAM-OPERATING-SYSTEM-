# Policy Requirements

Requirements state what must be satisfied for an action. The Policy Engine does not satisfy them.

Supported types:

- `operator_confirmation`
- `vault_unlocked`
- `maintenance_mode`
- `recovery_mode`
- `verified_bundle`
- `rollback_available`
- `physical_validation`
- `specific_profile`
- `specific_capability`
- `fresh_authentication`
- `single_use_approval`
